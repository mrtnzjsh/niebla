## Key Capabilities

<CardGrid>
  <Card title="Instant Virtual Workspaces" icon="rocket">
    Create workspaces in milliseconds. **NieblaFS** mounts the repository tree virtually, streaming file contents on demand and caching blobs locally.
  </Card>
  <Card title="Content-Addressable Storage" icon="document">
    Source files and multi-gigabyte binaries share a single [SHA-256](https://en.wikipedia.org/wiki/SHA-2) [content-addressable storage](https://en.wikipedia.org/wiki/Content-addressable_storage) engine—eliminating Git packfile bloat and `git-lfs`.
  </Card>
  <Card title="Cotejo Code Review" icon="laptop">
    Web code review built around immutable patchsets, intra-line word diffs, attention sets, and real-time [Server-Sent Events (SSE)](https://en.wikipedia.org/wiki/Server-sent_events).
  </Card>
  <Card title="Opt-In AI Review & Hints" icon="puzzle">
    Run automated review scripts, hermetic linters, or AI personas (via local Ollama/vLLM or your own API keys) with one-click patch application.
  </Card>
  <Card title="Linear Trunk History" icon="random">
    Commits serialize into a monotonic [trunk](https://en.wikipedia.org/wiki/Trunk-based_development) sequence (`r1, r2, r3...`) with automatic cloud rebasing for stacked changelists.
  </Card>
  <Card title="100% Open Source & Private" icon="setting">
    MIT-licensed with nothing proprietary or obfuscated. Niebla never phones home or collects external metrics—all data stays on your hardware.
  </Card>
</CardGrid>
